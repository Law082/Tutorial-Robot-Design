# Tutorial-Robot-Design

## Overview

This repository contains a comprehensive, step-by-step tutorial created as part of the Modular Mechatronic System (Translation - Rotation) project. This guide documents the entire workflow—from the initial geometric modeling in CATIA and dynamic simulation in SimMechanics, to the final component selection. It is specifically designed to help students and engineers replicate the design process, understand the underlying kinematic and dynamic principles, and learn how to practically extract and interpret forces and moments to properly size robotic components.
